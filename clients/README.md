# clients/

Chico-the-operator's private workspace. One subfolder per project Chico works, each holding that project's filled `brand.md`, its raw `learnings.md`, and working notes.

**This folder is gitignored.** It holds real business data: audiences, offers, numbers, results. It never goes to GitHub. Only this README is committed, as a signpost.

turma (the craft, in `../turma/`) stays generic and public. The private, project-specific data lives here. The learning loop only ever promotes a generalized, sanitized technique from here back into turma. Raw numbers never cross that line.

Projects that have their own repo can instead keep their `growth/brand.md` gitignored in that repo, and Chico reads it from there. Use this folder for projects without their own repo, or when Chico centralizes.
