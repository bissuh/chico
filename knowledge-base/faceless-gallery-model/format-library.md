# Carousel / Slideshow Format Library (2026)

The repeatable post FORMATS a faceless gallery account picks from. The rule: do not pour ideas into a generic slide skeleton. Pick a deliberate format, chosen by the signal you need that week, and vary formats so the feed never looks template-same (the #1 fatigue in 2026).

Compiled 2026-05-23 from web research. Sources at bottom. Companion to `research-dossier.md`.

## How to use this

1. Decide the signal you need this week: **reach** (sends/shares) or **conversion** (saves + opt-ins).
2. Pick a format from that column.
3. Build it as an open loop (result-first hook, payoff withheld to slide 5-6, slide 2 must reward the first swipe), 6-10 slides, dual CTA (save AND send).
4. Vary the format week to week. Same look (brand), different structure (format).

Note on discovery: carousels win SAVES and engagement but mostly reach existing followers + a re-serve bump. **Reels / short video are the cold-discovery engine.** A pure-carousel account grows slowly. Run Reels alongside (the research says ~60-70% Reels / 20-30% carousels for a growing account).

## Quick reference

| Format | Best for | Primary signal | Use it to |
|---|---|---|---|
| Swipe File ("Steal this") | Templates, prompts, scripts | SAVES (highest) | convert + micromagnet bridge |
| Checklist / Audit | Self-diagnosis, reference | SAVES + sends | convert |
| Step-by-Step / How-To | Repeatable processes | SAVES + completion | convert |
| Framework / System | Named mental models | SAVES + follows | convert + authority |
| Q&A / FAQ | Objection handling | SAVES | convert (mid-funnel) |
| By-the-Numbers / Stats | Research, data drops | SAVES + sends | authority + reach |
| Tool Roundup | Stack / resource lists | SAVES + sends | convert + reach |
| Mistakes-to-Avoid | Loss-aversion teaching | SAVES + sends | convert + reach |
| Before/After | Proof of a method | SAVES + follows (trust) | proof |
| Case Study / Story | One real outcome | SAVES + completion | proof + trust |
| Report / Findings | Original analysis | SAVES + follows | authority (hardest to copy) |
| Comparison ("X vs Y") | Decisions | SAVES + SENDS | reach + self-select |
| Myth-Bust | Correcting beliefs | SENDS + comments | reach |
| Contrarian / Hot Take | Positioning, POV | SENDS + comments | reach |
| Tier List / Ranking | Opinionated ranking | SENDS + comments | reach + debate |
| Identity ("which one are you") | Relatable types | SENDS (tags) | reach |
| This-or-That / Poll | Binary opinion bait | SENDS + comments | reach |
| Prediction / Trends | Forward authority | SAVES + sends | authority (fades fast) |

All are faceless-friendly. Text-on-design carousels are the most faceless-native format on either platform.

## Structures (the ones we will use most)

- **Swipe File:** Cover ("Steal these N [assets] for [outcome]") -> one copy-pasteable asset per slide (monospace/code styling) -> "save before this gets buried." Our tightest carousel -> opt-in bridge: preview the assets, the opt-in delivers the full installable skill.
- **Checklist / Audit:** Cover (problem) -> why it matters -> 6-10 check points -> scoring key -> CTA. Scoring key gives a reason to return and to send ("send to the person who handles X").
- **Framework:** Cover (name the framework) -> the problem -> one component per slide -> how they connect -> CTA. A named framework reads as IP and earns follows.
- **Myth-Bust:** Cover (the myth) -> myth/fact pairs -> "do this instead" -> CTA. Forwarded "to prove a point." Two-color split (myth muted / fact teal).
- **Comparison:** Cover -> the two options -> criterion-by-criterion -> "pick X if / Y if" -> CTA. Two-column slides.
- **By-the-Numbers:** Cover -> one big number + one context line per slide -> source slide -> CTA. Every number needs a named source on a slide or cut it.
- **Case Study:** Result-first cover -> who/context -> problem -> what they did -> result -> takeaway -> CTA. Run through story-craft.
- **Tier List:** Cover (grid teased) -> reveal tiers, S-tier last -> CTA. People swipe to the top tier and argue placements.

## 2026: working vs fatigued

**Working:** carousels resurgent via "double exposure" re-serve (high swipe-through gets reshown to non-swipers). Mixed-media carousels (1-2 short clips among image slides) flagged as the biggest open opportunity. Save-magnets: Swipe File, Checklist, Framework, How-To, Case Study. Send-magnets: Myth-Bust, Tier List, Comparison, Identity.

**Fatigued (avoid):**
- **Template sameness** is the #1 named fatigue: "vaguely similar slides where you used the same template and changed the words." Beat it by varying FORMAT, not by abandoning brand consistency.
- Generic listicles with vague titles. Fix with specific time/dollar outcomes.
- Broad "tag someone who" when the types aren't niche-specific.
- **AI-perfect polish is now a liability.** Canva's 2026 "Imperfect by Design" trend (DIY/scrapbook +90% YoY) + AI-fatigue backlash mean handcrafted, textured, human-trace visuals out-trust sterile AI-slick ones. TBP's Doré engraving canon already reads handcrafted, so it is an asset here, not a constraint.

## Data honesty

- **Primary (Socialinsider, ~35M posts, 2025):** carousels lead SAVES at every account tier; engagement ER carousel ~0.52-0.55% vs Reels ~0.50% vs image ~0.35%; carousels dominate views via re-serving; Reels lead comments and cold reach.
- **Platform-attributed but unconfirmed:** TikTok "carousels 1.9x likes / 2.9x comments / 2.6x shares vs video."
- **Aggregator / directional only (do not quote as fact):** "10% / 1.92% / 3x engagement," "DM shares 3-5x likes," "22% more saves," "completion <60% past 10 slides," "mixed-media 2.33% used by only 7%." Direction trustworthy, magnitudes unproven.
- No verified faceless business/AI-education account with documented per-format data was found. We will generate our own data and log it in `playbooks/faceless-gallery-engine.md`.
