# Reference bank for [PROJECT NAME]

Where ideas enter this project's content operation. `turma:pauta` (contract 1) maintains this file; the production skills draw from it so drafting never starts from a blank page.

Copy this file into your project as `growth/references.md`. It holds your raw thinking, so keep it out of public repos: add `growth/` to the project's `.gitignore`.

## How capture works

Capture wherever you are (chat, voice note, notes app, a link forwarded to yourself). The interface does not matter. What matters is that it lands here, distilled, the same day. A link with no insight attached is not a reference, it is a bookmark you will never open again.

## Entry format

```
### [YYYY-MM-DD] / [source title](url) / [tag]
- Insight: [the reusable idea in ONE line, in your words, not the source's]
- Why here: [why it matters for THIS project's positioning, one line]
- Connects: [an earlier reference, a published piece, or a draft it touches]
- Status: [raw / angled / used in [piece] / retired]
```

## Tags

Tag by theme so grounding packets can filter: `[product]` `[audience-pain]` `[competitor]` `[craft]` `[objection]` `[proof]` `[trend]` or whatever set fits this project. Keep the set small.

## Rules

- **Distill on capture.** One line of insight per reference, written in your words. If you cannot state the idea in one line, you have not extracted it yet.
- **Conversations count.** A reply, comment, or DM that pushes back on something you published is a reference. Often the best kind. Log it (paraphrased, no private names in shared files).
- **Mark what is spent.** When a reference feeds a published piece, set its status to `used in [piece]`. The bank should show what is fresh.
- **Prune monthly.** Retire what no longer fits the positioning. A bank full of dead references stops being read.
