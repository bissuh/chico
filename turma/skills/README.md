# turma/skills

The specialists. Each is a `SKILL.md` (frameworks + methods) invoked as `turma:<name>`. Every one reads the host project's `brand.md` for voice, audience, and goal, then applies its method. None hardcodes a brand.

**Craft (the frameworks the jobs use):**
- `story-craft`: persuasion via the 5-line framework
- `name-craft`: naming via Placek's Lexicon method, with domain checks
- `micromagnet-craft`: 2-minute opt-in tools
- `anti-ai-linguo`: the final voice pass, strips AI tells and dashes (runs last)
- `power-law`: treat content and growth as a power law, run the barbell

**Tasks (the jobs you ask for):**
- `carousels`: generate deep social carousels from a topic or a source piece
- `optimize-post`: score and rewrite a post/page/email for quality and engagement
- `ghostshelf`: build and run a faceless page that sells a digital product
- `cta-machine`: an AI-assisted YouTube Shorts growth machine

**Connectors (read-only data):**
- `beehiiv-connector`: read any beehiiv publication's state
- `youtube-connector`: read any YouTube channel's state and do competitor research
- `search-console-connector`: read Google Search Console (organic traffic, queries, pages, rankings) for SEO analysis. Walks the user through the one-time credential setup if it isn't configured yet.

For jobs turma does not cover directly (SEO audits, ad copy at scale, long email sequences), Chico uses the general marketing skills installed in the session and frames them with `brand.md`.
