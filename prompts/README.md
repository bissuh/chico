# prompts/

Copy-paste prompts that turn any AI (Claude, ChatGPT) into a specific advisor or tool. Unlike `skills/`, which install into Claude Code, these are plain prompts: open your AI, paste, go. No setup, no terminal.

Each file explains what the prompt does, how to use it, and what you get. Every one is built and used on TBP first.

- **`founders-triangle-diagnostic.md`**: an honest advisor that interviews you and scores your one-person AI business idea on Domain, Depth, and Distribution, then hands you a first move. Pairs with the newsletter edition on the Founder's Triangle.
